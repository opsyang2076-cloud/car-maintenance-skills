# 故障初步诊断指南

> 目的：在车主发现异常后，提供一份**不替代专业技师**的初步判断工具。
> 用来判断：①是否必须立即停车叫救援；②能否低速开到就近修理厂；③可否等下次保养一并处理。
> 最后更新：2026-08

---

## 一、紧急分级总则

所有异常按**安全风险**分为四级，分级标准高于"是否还能跑"：

| 级别 | 判定 | 处置 | 典型表现 |
|------|------|------|----------|
| 🔴 **S 级 立即停车** | 涉及制动失效、转向失控、轮胎爆裂、自燃起火、机油压力丧失 | **靠边停车、熄火、开双闪、撤离至安全区、致电 122/12122 救援** | 刹车踏板踩空、方向盘自由转动、底盘明火、机油灯常亮 |
| 🟠 **A 级 缓行就近** | 影响驾驶但可控，就近 4S/修理厂不超 20km | **避开高速/山路、不开夜路、缓行至就近门店** | 水温偏高、单缸失火、ABS灯偶亮 |
| 🟡 **B 级 短期预约** | 不影响安全但有损机械，1–2 周内进店 | **记录发生条件，下次保养或预约专项检测** | 异响、轻微渗油、怠速抖动 |
| 🟢 **C 级 暂可观察** | 设计特性或偶发，非故障 | **无须处置，持续观察是否恶化** | 冷启动轰、新车少许烧机油、启停频繁 |

> **判断冲突时取高级别。** 例如"轻微异响 + 底盘渗油"按 B 级处理（先就渗油）。
> **C 级误判为高级是浪费，A 级误判为 C 级是事故。** 不能确定的就取高级。

## 二、仪表盘警示灯速查

### 灯号分级

| 图标颜色 | 含义 | 默认级别 | 处置 |
|----------|------|---------|------|
| 🔴 红色常亮 | 系统失效或关键参数越界 | ≥ A 级 | 立即处置，部分需 S 级 |
| 🟠 黄色常亮 | 功能受限但未必失效 | ≥ B 级 | 预约检测 |
| 🟠 闪烁 | 严重但不立即致命 | ≥ A 级 | 缓行就近 |
| 🟢 绿/蓝色 | 提示或正常 | C 级 | 无须处置 |

### 主要警示灯对应

| 灯号 | 常亮含义 | 默认级别 | 立即处置 vs 暂可缓 |
|------|----------|---------|---------------------|
| **机油压力** 🛢️ | 油压 <0.3 bar | **S 级** | **立即停车熄火**，继续运转 30 秒即可抱瓦 |
| **水温** 🌡️ | >110°C 或冷却液缺失 | **S 级** | 雾灯停车、不可立即揭盖（喷罐） |
| **刹液低** ⚠️ | 制动液低于 MIN | **A 级** | 缓行就近，不可高速 |
| **ABS** | ABS 关闭，基础刹仍有效 | B 级 | 预约诊断 |
| **EPS电动助力** | 转向助力丧失 | A 级 | 缓行就近，方向变重 |
| **发动机故障** | 多义：失火/传感器/排放 | B 级 | 读码后定位 |
| **电池/充救灯** | 发电机或电瓶异常 | A 级 | 缓行就近，关闭非必要用电 |
| **胎压灯** | 胎压异常或漏气 | A 级 | 慢行补气或换胎 |
| **气囊灯** | SRS 系统异常 | B 级 | 预约，气囊失效不拦驾驶 |
| **四驱灯/AWD** |四驱离合异常 | A 级 | 避陡坡/沙泥，就近检测 |
| **颗粒捕捉器/GPF灯** | 柴油机或直压缸 GPF 堵塞 | B 级 | 高速工况再生，常堵降级 A |
| **驻车灯/雷达灯** | 辅助系统异常 | C 级 | 暂可缓 |
| **新能源三电灯** | 电池/电机/电控异常 | A 级 | 退出高压工况、就近检测 |

> ⚠️ **机油灯、水温灯** 必须按 S 级处置——这两灯亮起后再坚持开，机械损毁概率极高，且事后保险公司可能以"驾驶人不听劝"为由拒赔。

## 三、按异常类别诊断流程

### 类别 1 — 异响

异响是 B 级最常见的来源，但部分异响升级为 A/S 级。按"工况 → 频次 → 位置"逐层定位：

```
异响
 ├─ 踩油门才出现 → 加速工况
 │   ├─ 低频闷响（<10Hz） → 找下悬挂/球头/平衡杆胶套
 │   ├─ 中频咯哒（金属） → 找正时齿轮/链条张紧器
 │   └ └高频锐鸣（>1kHz） → 找涡轮/进气歧管/排气垫
 ├─ 刹车才出现 → 制动工况
 │   ├─ 踩粉 → 刹车盘边沿生锈或片硬点 → B 级
 │   ├─ 金属磨响 → 片磨至铁/片厚度<3mm → A 级
 │   └ ┐刹液本软磨 → 刹液本失效 → A 级
 └─ 刹车才出现 → 惰速工况
     ├─ 怠速或近停 → 找排/风扇/水泵/发电机轴承
     ├─ 踩油 → 找正时/气门脚/连杆轴瓦 → A 级
     └ 折速异或 → 找传动胶/轴承/悬挂胶 → B 级
```

#### 常见异响速查

| 工况 | 响声描述 | 多见原因 | 级别 |
|------|----------|---------|------|
| 刹车时 | "冝冝"轻响 | 刹车盘边生锈、片硬点 | B 级 |
| 刹车时 | 金属刮磨 | 刹车片磨尽（<3mm） | A 级 |
| 刹速时 | 闷响随转速 | 排气垫漏、三元催化碎 | B 级 |
| 怠速 | "哒哒哒"金属 | 气门脚间隙变大 | A 级 |
| 怠速 | "吱吱"连续 | 发电机/水泵轴承 | B 级 |
| 趲坎 | "咯咯咯"闷 | 悬挂胶套老化 | B 级 |
| 越坎 | "咔哒"瞬响 | 平衡杆胶套或球头旷 | B 级 |
| 换档 | "咔"单声 | 变速箱接合响（设计或异常） | B/C 级 |
| 超速 | "明"连续鸣 | 胎面/轴承/涡轮 | A 级 |

> **判明响源"远近"：** 闭窗一耳听、再升窗一耳听、再升窗二耳听，三者对比可分近底盘/中发动机/远排气管。

### 类别 2 — 油液渗漏

渗漏分**颜色识别**和**位置识别**两步。

#### 油液颜色识别

| 颜色 | 多半是什么 | 位置 | 级别 |
|------|------------|------|------|
| 黄红透 | 刹车油（DOT3/4，吸水） | 各轮内侧、刹总泵下 | A 级（刹油少很危险） |
| 红/绿 | 冷却液（G11 红、G13 粉红、G12++ 紫） | 车头散热、水管接头 | A 级（低温缺冷却） |
| 黑褐 | 机油 | 发动机中下、变速箱前 | B 级（量少可缓） |
| 红/黄透 | 自动变速箱油 ATF | 变速箱下、半轴油封 | B 级 |
| 橙红 | 助力转向油 | 转向器/助力泵管接头 | B 级 |
| 清/浅黄 | 减震器油 | 各轮内侧 | C 级（减震油少漏） |
| 淡蓝 | 雨刮水 | 挡风下、雨刮泵 | C 级 |

> ⚠️ **冷却液和刹油的颜色会随品牌配方不同。** 例如奔驰用橙色冷却液、宝马用蓝色，颜色仅作粗判，最终以**位置 + 闻味**双重确认。

#### 渗油位置速判

| 位置 | 多见原因 | 级别 |
|------|---------|------|
| 发动机顶盖（气门室盖垫） | 胶垫老化，机油渗 | B 级 |
| 发动机中段（油底壳垫） | 油底壳胶老化 | B 级 |
| 变速箱与发动机接面 | 半轴油封/接面垫 | B 级 |
| 刹车分泵内侧 | 分泵活塞锈蚀回位不良 | A 级 |
| 轮胎内侧上方 | 减震器顶胶渗 | C 级 |
| 冷却水箱下沿 | 水箱锈蚀或水管松 | A 级 |
| 助力转向器管接头 | 油管老化 | B 级 |

> **渗量估算法：** 放一张干净硬纸板在车底对应位置过夜，次日看油斑直径和颜色。
> - 斑径 <5cm 干后无新迹 → B/C 级，可缓
> - 斑径 5–15cm 且湿 → B 级，1–2 周内进店
> - 斑径 >15cm 或速见新滴 → A 级，缓行就近

### 类别 3 — 异味

| 气味 | 多半来源 | 级别 |
|------|---------|------|
| 烤橡皮味 | 刹车过热、胎过热、 clutch 烧 | A 级 |
| 甜腻味 | 冷却液漏到炽热部件 | A 级（防毒） |
| 机油焦味 | 机油严重漏到排气歧管 | B 级 |
| 烤电线味 | 线束过热或元件烧毁 | **S 级**（短路自燃风险） |
| 汽油味（启动后散不去） | 燃油管漏或炭罐失效 | A 级 |
| 霉味 | 空调滤芯湿或冷凝水道堵 | C 级 |
| 酸味 | 电瓶电解外泄 | B 级（充电室积氢） |
| 蛋臭味（新能源） | 电池液热失控征兆 | **S 级**撤离+119 |

> **烤电线味和蛋臭味是 S 级**——前者易致自燃、后者是电池失控前兆，必须立即停车撤离致电。

### 类别 4 — 抖动与乏力

#### 抖动分类

| 工况 | 类型 | 多见原因 | 级别 |
|------|------|---------|------|
| 怠速 | 周期性强 | 个别缸失火、火花塞/点火线圈坏 | A 级 |
| 怠速 | 随机弱 | 怠速马达/节气门脏 | B 级 |
| 加速 | 抖随转速 | 高压线漏、点火脚坏、空滤堵 | A 级 |
| 加速 | 闷拖不动 | 燃油泵/喷嘴堵、三元催化碎 | A 级 |
| 恒速 | 车身轻颤 | 轮胎动平衡或钢圈变形 | C 级 |
| 超坎 | 方向传颤 | 转向节球头旷、悬挂胶老化 | B 级 |
| 刹车 | 方向抖 | 刹车盘端跳超限（厚薄不均） | A 级 |

> **加速乏力 + 抖** 多半是点火或燃料系，**刹时方向抖**多半是刹盘，**超坎方向颤**多半是悬挂——三类不要混。

### 类别 5 — 异状（外观）

| 异状 | 多见原因 | 级别 |
|------|---------|------|
| 轮胎偏磨单侧 | 四轮定位失准或悬挂变形 | B 级 |
| 轮胎双侧磨肩 | 气压过低或高速过载 | B 级 |
| 轮胎中磨条 | 气压过高 | C 级 |
| 钢圈变形 | 撞坎/路坎，需做动平衡 | B 级 |
| 排气黑烟（柴油车除外） | 烧机油、空燃过浓 | B 级 |
| 排气蓝烟 | 烧机油（气门脚、活塞环、涡增） | B 级 |
| 排气白烟（暖机后仍） | 冷却液入缸（缸垫冲） | **A 级** |
| 车头油渍+杂质 | 散热水箱渗气 | A 级 |
| 车底新油斑 | 见"类别 2"渗油 | 按对应级 |

## 五、新能源车专属诊断

### 1. 电池系统

| 现象 | 多半原因 | 级别 |
|------|---------|------|
| SOH 一年内降 >5% | 单体早期衰减或 BMS 估算偏差 | B 级 |
| 充电至 80% 后速度突然变慢 | **属正常保护策略**，非故障 | C 级 |
| 怠耗异常（每夜掉 >5%） | 哨兵模式/预调温/BMS 失眠 | B 级 |
| SOC 跳变（如 30%→22%） | 单体压差大或 BMS 重算 | A 级 |
| 高压绝缘告警 | 电池包内凝露或接插件松 | **S 级**撤离 |
| 蛋臭味 | 电解液热失控征兆 | **S 级**撤离 +119 |

### 2. 电机与电控

| 现象 | 多半原因 | 级别 |
|------|---------|------|
| 加速咯顿 | 逆变器或电机退磁早期 | A 级 |
| 高速闷响 | 减速器齿面磨损 | B 级 |
| 动能回收突然失效 | 电池温度过低或过高 | C 级（自动保护） |
| 充电限功率（如限制 60kW） | **属温度保护策略**，非故障 | C 级 |

### 3. 直流充电桩

| 现象 | 处置 |
|------|------|
| 枪锁不退 | 关闭充电，按桩上"急停"再联系客服 |
| BMS 与桩通信失败 | 换桩，同桩两次失败回店刷固件 |
| 充电中跳闸 | 检查桩端漏电保护灵敏度，必要时升级漏保 |

## 六、缓行就医决策树

出现 A/S 级征兆后，**是否还能开**取决于：

```
能否缓行就近？
 ├─ S 级征兆 → 否，立即停车叫救援
 ├─ A 级征兆
 │   ├─ 距离最近门店 >20km 或山路/高速 → 否，叫拖车
 │   ├─ 刹系/转向/胎涉及 → 否，叫拖车
 │   └ ├级灯+夜间 → 否，叫拖车
 │   └ ├可闭用电器/不载重/日间/距离近 → 是，缓行
 │   └ 改善未可见或恶化 → 否，停车叫救援
 └─ B 级征兆 → 是，1–2 周内预约
```

### 缓行就医规则

1. **避开** 高速、山路、夜路、大雨/雾/沙、拥堵高峰
2. **关掉** 非必要用电（空调、座椅加热、音响、导航定位）
3. **不载重**，不拖挂，不超转
4. **行车中** 每 10km 复查一次仪表、异响、异味、踏感
5. **恶化立即停车**——缓行不是承诺开到，是开到最近可停之处
6. **到店即出示** 故障观察记录（发生工况、频次、伴生现象）

## 八、与保养流程的关系

- 用户报告异常时，**优先按本指南输出诊断**，再回到 SKILL.md 的 Step 2 保养等级判定。
- 诊断中如发现保养关联项（如刹片<3mm、油底渗油），应在 Step 3 保养项目清单中升级对应项目的紧急度。
- 诊断级别 ≥ A 级时，**Step 4 价格比价自动聚焦到对应专项修理**（如刹系不能在路边店做）。
- 诊断级别 = S 级时，跳过 Step 2–6，直接处置为"停车撤离+救援"。
