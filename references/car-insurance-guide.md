# 车险购买与推荐指南

> 基于2020年车险综合改革（综改）后的最新条款体系。
> 最后更新：2026-01

---

## 一、车险结构总览（2020综改后）

### 强制险

| 名称 | 是否强制 | 赔偿上限 | 说明 |
|------|---------|---------|------|
| 交强险 | 必须购买 | 20万元 | 仅赔第三方，保额较低，建议仅作保底 |

### 商业险主险

| 名称 | 说明 |
|------|------|
| 机动车损失保险（车损险） | 保自己的车，综改后已合并盗抢/玻璃/自燃/涉水/不计免赔/无法找到第三方 |
| 第三者责任保险（三者险） | 保第三方人员伤亡/财产损失，按保额赔付 |
| 车上人员责任保险（座位险） | 保本车乘客，按每座赔付 |

### 常见附加险（需在主险基础上附加）

| 附加险 | 作用 |
|--------|------|
| 医保外用药责任险 | 三者险/座位险出险时，覆盖自费药部分（强烈建议买） |
| 车身划痕险 | 无明显碰撞痕迹的漆面划痕 |
| 车轮单独损失险 | 轮胎/轮毂单独损坏 |
| 新增设备损失险 | 改装件/加装设备的损失 |
| 法定节假日限额翻倍险 | 节假日三者险保额翻倍（100万→200万） |
| 新能源车险专属附加险 | 充电桩损失险、外部电网故障损失险等 |

## 二、推荐配置方案

### 方案 A：新车 / 价值较高车辆（推荐）

| 险种 | 建议保额 | 年保费参考 |
|------|---------|-----------|

| 车损险 | 按车辆实际价值 | ¥3,000–8,000 |
| 三者险 | **300万起步**（一线500万） | ¥1,500–3,000 |
| 医保外用药（三者） | 同三者 | ¥50–150 |
| 座位险 | 每座1–5万 | ¥200–500 |
| 不计免赔 | 已含车损，无需单独买 | — |

> **合计年保费参考：** 新车约 ¥5,000–12,000（视车型和地区）

### 方案 B：家用普通家用车（性价比方案）

|------|---------|-----------|

| 医保外用药 | — | ¥50–100 |
| 驾乘意外险 | 每座30–50万 | ¥300–800 |

### 方案 C：老旧车辆（车龄 8 年以上）

| 险种 | 建议 | 说明 |
|------|------|------|
| 交强险 | 必须买 | — |
| 三者险 | **200万** | 不可省，责任风险不变 |
| 车损险 | **不建议买** | 车辆残值低，出险不划算 |
| 医保外用药 | 建议附加 | 保费很低 |
| 座位险/驾乘险 | 按需求 | 保护家人 |

> **合计年保费参考：** 约 ¥1,500–3,000

## 三、各场景针对性建议

### 一线城市车主

- 三者险必须 **300万** 以上，500万更佳
- 原因：豪车密度高、人身损害赔偿标准高（北京/上海死亡伤残赔偿超150万/人）
- 强烈建议加医保外用药附加险

### 经常跑高速/长途

- 三者险 300万+
- 座位险/驾乘险保额提高（建议每座 30–50 万）
- 考虑加法定节假日限额翻倍

### 经常载家人

- 购买「驾乘意外险」优于「座位险」
- 原因：驾乘险不限座位，跟人不跟车，保额更高

### 新能源车车主

- 必须购买 **新能源汽车专属商业保险**
- 三电系统（电池/电机/电控）已在专属条款内覆盖
- 自燃险已纳入车损险主险，无需单独购买
- 强烈建议加「外部电网故障损失险」
- 充电时发生事故（充电桩/电网故障）可获赔

## 四、续保省钱策略

### 1. 把握续保时机
- 提前 **30–45 天** 续保，避免脱保后的惩罚
- 年底前（11–12月）多家保险公司会提前放折扣，可横向比价

### 2. 利用无赔款优待系数（NCD）

| 连续无出险年数 | NCD系数 | 折扣幅度 |
|--------------|---------|---------|
| 第 1 年（首年） | 1.00 | 基准 |
| 第 2 年 | 0.85 | 15% |
| 第 3 年 | 0.70 | 30% |
| 第 4 年 | 0.60 | 40% |
| 第 5 年及以上 | 0.50 | 50% |

> **结论：** 连续不出险 5 年，商业险保费直接打半！

### 3. 多家比价
向以下三家公司同时询价：
- **人保PICC** — 网点最多，理赔快，价格略高
- **平安产险** — APP体验好，服务便捷，价格中等
- **太保CPIC** — 性价比较高，中小城市服务不错

### 4. 减少不必要附加险
以下项目**不建议单独购买**或已并入主险：
- ❌ 划痕险（5年以上老车没必要）
- ❌ 发动机涉水险（已并入车损）
- ❌ 盗抢险（已并入车损）
- ❌ 玻璃单独破碎险（已并入车损）
- ❌ 不计免赔（已并入车损）

## 五、出险与理赔技巧

### 何时应该报案、何时私了

| 场景 | 建议 |
|------|------|
| 轻微剐蹭（维修费 < 500元） | 建议私了，避免次年保费上涨 |
| 双方都有责任 | 走保险，保留现场照片 |
| 有人伤 | 必须报交警和保险公司 |
| 涉及豪车/公共设施 | 必须走保险，私了风险极高 |
| 对方全责但拒绝赔偿 | 联系己方保险公司代位追偿 |

### 出险影响保费计算

- 出险 1 次：次年 NCD 系数重置为 1.0（商业险保费上涨约 25–35%）
- 出险 2 次：商业险保费可能上涨 50%+
- 出险 3 次以上：部分保险公司拒保或要求较高附加条件

> **结论：** 小额损失（< 1000元）建议私了，保留连续无出险记录更划算。

## 六、新能源车险特别说明

### 2021年新能源车专属条款要点

| 传统车险问题 | 新能源车专属条款解决 |
|------------|-------------------|
| 电池在事故中受损难以定损 | 专属条款明确电池单独损失纳入车损险 |
| 自燃风险高，需单独买自燃险 | 自燃险已并入车损险主险 |
| 行驶中因外部电网故障导致电池损坏 | 新增「外部电网故障损失险」 |
| 充电桩被损坏需单独投保 | 新增「充电桩损失险」 |
| 电池自然衰减保险公司不赔 | 仍不赔（属于正常磨损） |

### 新能源车投保建议

1. 购买时选择有新能源车险承保资质的保险公司
2. 务必确认保单明确注明覆盖「电池/电机/电控系统」
3. 家用充电桩建议单独投保「充电桩损失险」（约 ¥30–80/年）
4. 长途旅行可考虑加保「道路救援服务」

## 七、常见保险术语速查

| 术语 | 含义 |
|------|------|
| 保额 | 保险公司最高赔付金额 |
| 免赔额 | 出险时自己承担的部分金额 |
| 不计免赔 | 将免赔额转嫁给保险公司（综改后已并入主险） |
| NCD系数 | 无赔款优待系数，不出险次数越多折扣越大 |
| 代位追偿 | 对方全责不赔时，己方保险公司先行赔付后再追偿 |
| 三者险 | 保第三方的，赔别人（人+车+物） |
| 车损险 | 保自己的车，修自己的车 |
| 座位险 | 保本车乘客 |
| 驾乘险 | 保车上人员，可选跟车或跟人 |
