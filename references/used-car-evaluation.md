> 目的：给买家一份**结构化的二手车评估工具**，覆盖车源筛选、调表识别、重大事故痕迹判断、关键部件寿命估算、价格锚点、过户前后检测清单。

## 一、选购前自问：是否需要买二手车

### 二手车的真实价值边界

| 优势 | 劣势 |
|------|------|
| 价格低 30–50%，同样预算可上一档 | 折旧曲线未走完，仍有持续贬值 |
| 第一任车主已承担最陡折旧 | 质保剩余期短或已过 |
| 购置税按评估价计，更低 | 历史不确定性（事故/维修/调表） |
| 保险按评估价计，更低 | 充电/三电质保通常不跟车不跟人 |
| 同价可选更高配置 | 售后无 7 天可退等新车权益 |

### 适配画像

| 画像 | 是否推荐二手车 |
|------|---------------|
| 预算受限刚需用车 | ✅ 推荐 |
| 技术敏感愿意检测投入 | ✅ 推荐 |
| 新手驾龄 <1 年 | 🟡 推荐，但选 3 年内次新车 |
| 蔑面值洁癖型 | ❌ 不推荐，买新车 |
| 新能源早期采用者 | 🟡 谨慎，三电质保问题多见 |
| 一线限号摇号一族 | ✅ 推荐，号牌比车贵 |

## 二、车源筛选四步法

### Step 1 — 平台与卖家筛选

| 渠道 | 优势 | 风险 | 用法 |
|------|------|------|------|
| 闲二手车 | 个人车源多、价格透明 | 无质保、个人诚信差 | 用于"同款比价"参照 |
| 瓜子二手车 | 商家质保、七天可退 | 售价含利润，比个人贵 8–15% | 买保中期首选 |
| 人人车 | 检测后上架、315 项复检 | 售价偏贵 10–20% | 不愿花检测费时选 |
| 4S 认证二手车 | 原厂检测、部分延保 | 售价最贵，常 +15–25% | 买豪车上档车选 |
| 短视频/直播车源 | 直观、可互动 | 话术多、易冲场 | 仅用于初筛 |

**筛除规则：**
1. 卖家注册时长 <6 月 + 评分 <4.5 → 直接排除
2. 同一车照片在多平合出现（盗图） → 排除
3. 描述出现"车况精品""无需检测"等回避检测关键词 → 排除
4. 调价频次 >3 次/月且每次降幅 >5% → 可能事故车甩卖 → 谨慎
5. 显少保养记录和 VIN 查询 → 排除

### Step 2 — VIN 查询

**车架号（VIN）17 位**是二手车鉴定的核心。拿到后必查：

| 查询项 | 平台 | 费用 | 重点 |
|---------|------|------|------|
| 出险记录 | 查博士/蚂蚁看车/4S | ¥20–80 | 是否重大事故/水泡/火烧 |
| 保养记录 | 同上 | 同 | 间隔是否规律、里程是否连贯 |
| �召回记录 | 国家市场监管总局站 | 免费 | 是否召回未处理 |
| 抢挡记录 | 各品牌官方站 | 免费 | 是否原厂拆装 |
| 押押查封 | 中国执行信息公开网 | 免费 | 是否被押封 |

**出险记录判读要点：**
- "损毁""全损""推定全损" → 曾重大事故，慎买
- "水淹""暴雨""涉水" → 水浸车，慎买
- "三者物损 <5000元" → 一般小刮蹭，可买
- "本车××部位损" → 看具体部位，刹系/转向系损则慎买

**保养记录判读：**
- 间隔应连贯，间隔突然跳变 → 调表嫌疑
- 最后一次保养里程 >当前里程 → 调表嫌疑
- 机油品牌从贵转便宜 → 可能车主已不愿投入，车况下滑
- 不同 4S 店品牌混查记录 → 多地流转，慎买

### Step 3 — 看车八项硬指标

到现场前**先要求卖家准备好以下全部**，缺一不买：

| # | 硬指标 | 缺则处置 |
|---|--------|---------|
| 1 | 登证原件 + 复印 | 缺则拒买 |
| 2 | 行驶证原件 + 复印 | 缺则拒买 |
| 3 | �购车发票或上次过户凭证 | 缺则降级议价 |
| 4 | 保养手册含首次保养页 | 缺则加查 4S 系统记录 |
| 5 | 全套钥匙含主钥+副钥 | 缺则降级议价 |
| 6 | 完整点烟器、工具包、备胎 | 缺则降级议价 |
| 7 | 车架号钢印清晰可拓印 | 错改则拒买 |
| 8 | 现场能冷启动怠速 ≥3 分钟 | 不能则拒买 |

### Step 4 — 现场九看九问

到现场后，按以下顺序检查：

#### 外九看

| 看 | 验什么 | 正常 | 异常信号 |
|----|--------|------|---------|
| 漆面色差 | 是否补漆 | 全车同泽 | 不同部件明显色差 → 撇补 |
| 钢缝胶条 | 是否原厂 | 均匀一致 | 不均、过宽、过厚 → 撇拆换 |
| 螺栓漆 | 是否拆过 | 原厂漆面完 | 被拧过掉漆 → 拆过 |
| 玻璃日期 | 是否原厂 | 4 位码一致 | 不同年份 → 换过玻璃 |
| 轮胎日期 | 是否超期 | 4 位 DOT周 | 5年以上/纹深度<1.6mm → 应议价 |
| 排气管内壁 | 是否烧机油 | 干灰 | 黑油渍 → 烧机油 |
| 底盘渗油 | 是否漏 | 干净 | 新滴油 → 渗油 |
| 备胎坑 | 是否进水 | 干 | 湿/锈 → 密封不良或水浸 |

#### 里九问

| 问 | 验什么 | 正常 | 异常信号 |
|----|--------|------|---------|
| 安全带日期 | 是否换 | 与购车年相近 | 远晚于购车 → 拆撞换过 |
| 方向盘磨纹 | 与里程合 | 与宣称里程合 | 磨光秃配低里程 → 调表 |
| 刹车踏纹 | 与里程合 | 适度磨损 | 极磨配低里程 → 调表 |
| 油门踏纹 | 同上 | 适度 | 极磨 → 调表 |
| 充电口 / AUX | 是否用过 | 无磨痕 | 磨痕 → 长期充大电器 |
| 备忘灯 | 自检是否亮 | 自检亮后灭 | 常亮 → 故障 |
| 灰尘均否 | 是否泡水 | 均灰 | 缝内泥锈/坐椅下净 → 泡水 |
| 储物箱味 | 是否泡水 | 无霉 | 霉味 → 泡水嫌疑 |

## 三、调表识别五大法

### 1. 保养记录对勘法（最准）

```
最后一次保养里程 vs 当前里程
 壤距 > 当前里程 → 调表嫌疑（强）
 间隔跳变（如上保 5000→下次保 30000） → 调表嫌疑（中）
```

### 2. 易磨件对照法

| 部件 | 5万km参考磨损 | 调表嫌疑信号 |
|------|--------------|-------------|
| 方向盘 3 点位 | 轻微脱漆 | 全秃 |
| 油门/刹踏 | 轻磨 | 纹路磨光 |
| 换档柄 | 轻磨 | 光亮 |
| 座椅外侧 | 轻皱 | 深皱/破缝 |
| 门手扶 | 轻 | 松旷 |

### 3. 灰尘积累法

- 中控硬塑件缝隙灰 → 与里程正相关
- 后备箱深处缝灰 → 与里程正相关
- 灰尘明显比宣称里程多 → 调表（极少调多）

### 4. 胎面胎法

- 同一车胎面 DOT周间隔 <2 年且胎面品牌同 → 一手胎，看磨损深度
- 胎面磨到警线（1.6mm）但宣称里程 <4 万 km → 调表嫌疑

### 5. OBD 读取法（终极）

带 OBD 蓝牙诊断仪（¥30–80），读取：
- 行驶里程 ECU 计数（多数车的 ECU 内部计与仪表盘独立计）
- 平均车速、累计油耗、累计运转时长

若 ECU 计数显著 > 仪表盘里程 → 调表。

> **仪表盘调表是软件改字**，OBD 内部计是硬改不掉的——这是最可靠的调表识别法。

## 五、关键部件剩余寿命估算

在看车现场用以下公式粗算：

```
某件剩余寿命 = MIN(里程寿命 - 当前里程, 年限寿命 - 当前车龄)
```

### 主要件寿命参考

| �件 | 里程寿命 | 年限寿命 | 查看要点 |
|----|---------|---------|---------|
| 正时皮带 | 8–10 万 km | 8 年 | 是否换过（保养记录） |
| 正时链条 | 15–20 万 km | 免维护 | 听冷启动是否噪 |
| 刹片 | 3–5 万 km | / | 厚度是否 >3mm |
| 刹盘 | 8–10 万 km | / | 端跳是否 <0.05mm |
| 胎 | 4–8 万 km | 5 年（DOT 周） | 纹深度 >1.6mm 且 <5 年 |
| 电瓶 | / | 3–5 年 | 启停寿命更短 |
| 冷却液 | 4–6 万 km | 2–3 年 | 是否变色（粉/橙/紫） |
| 刹液 | 4 万 km | 2 年 | 含水率（4S 可测） |
| 火花塞 | 4–10 万 km | / | 是否换过（依材质） |
| 减震器 | 6–10 万 km | / | 看顶胶是否渗油 |
| 悬挂球头 | 8–12 万 km | / | 听超坎是否咯响 |

### 折价规则

发现某件接近寿命末端，按新车件价的 60–80%向卖家索降：

```
议价额 = Σ(近寿命件剩余寿命% × 件价 × 0.6–0.8)
```

## 七、议价实战

### 议价次序

1. 先凭 VIN 出险保养记录 → 指出 1–2 处瑕疵
2. 再凭现场九看九问 → 指出 1–2 处瑕疵
3. 凭关键件剩余寿命估算 → 指出 1–2 处近寿件
4. 凭同款成交价中位数 → 给出锚点

每次只抛 1 个点，让卖家回应后再抛下一个。

### 议价禁忌

- ❌ 一次性抛所有瑕疵 → 反成强势 → 卖家拒售
- ❌ 超同款成交价下限 10% → 卖家拒售
- ❌ 在已签意向后大幅削价 → 卖家可索违约
- ❌ 调表、泡水、火烧证据未拍 → 卖家赖 → 已拍可索退

### 议价成交后

**付款前** 还要：
1. 暂扣登记证行驶证复印件（卖家盖暂扣印）
2. 暂扣保险复印件
3. 双方签书面购车合同（闲/瓜子上下载模板，含 VIN、当前里程、车况瑕疵清单、价格、过户时限、违约条款）
4. 全款或定金进**第三方资金监管**（闲有"放心付"，瓜子有"资金托管"），不要直接打款

### SOH 查询

要求卖家陪同到品牌自营或售后读电池健康度（SOH，State of Health）：

| SOH | 含义 | 折价 |
|------|------|------|
| ≥95% | 近新车 | ×1.00 |
| 90–95% | 正常衰减 | ×0.95 |
| 85–90% | 可接受 | ×0.88 |
| 80–85% | 接近警线 | ×0.75 |
| <80% | 需换电 | ×0.50（扣换电成本 ¥5–10 万） |

### 充电桩权益

蔚来自营桩权益跟人不跟车，过户后新车主无自营桩权益；特斯拉超充权益跟车不跟人。
