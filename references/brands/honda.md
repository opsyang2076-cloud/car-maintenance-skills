## 旁路自保 Tips

1. **MM 机油识别**：本田 Maintenance Minder 系统会根据驾驶习惯动态缩短机油间隔，MM 灯亮起后按 RESET 读取计数器；5,000 km 间隔是 MM 提示极限，不是"必须立即换"，但不应拖延超 1,000 km。
2. **1.5T 机油增多对策**：2016–2020 款 L15B/L15C 1.5T 地梦在冷区/短途高发机油增多；本田手册明确重度驾驶可加 5W-30 缓解，外油标 API SP / ILSAC GF-6 0W-20 可用，保油贴含 0W-20。
3. **CVT Type 3/Type 4 不可混加**：本田 CVT 思域、型 R 为 CVTF Type 3；CR-V/�影 款为 CVTF Type 4，型号不同油色不同（紫/红），混加导致泵体磨损与报错。
4. **DOT 4 vs DOT 5.1**：本田中端车使用 DOT 4 �车油；思域 Type R 与部分高性能款用 DOT 5.1，不可与 DOT 4 �湛加，更换时须原厂规。
5. **�动 SOH 年检不可漏**：本田三电质保要求每 12 个月进店检测动力电池健康；4S �主动召唤，漏检将降为常规 8 年/10 万 km，漏检 3 次�质保失效。
