## 机油与油液规格

| 部件 | 规范/型号 | 厂方规格编号 | 推荐粘度 |
|------|------------|--------------|----------|
| 发动机机油 | API SP / ILSAC GF-6 | TOYOTA Genuine Oil 0W-20 | 0W-20（主推）；5W-30 仅限高负载旧款 |
| 长效款机油 | API SP / ILSAC GF-6 | TOYOTA Genuine Oil 5W-30 | 5W-30（部分 2.0T 高负载） |

| 变速箱油（AT/CVT） | ATF WS（Toyota World Standard） | JWS 336 / ATF WS | ATF WS（CVT 可超期但不免，工况下建议 60,000 km 检） |

| 减速箱油（EV） | ATF WS | JWS 338 | ATF WS |

## 4S 常见过度推销项

| 项目 | 是否必要 | 建议间隔 | 自检方法 |
|------|----------|-------------|----------|
| 洗节气门 | 多数不必要 | 40,000–60,000 km（视实测） | 怠速稳定则不洗；怠速抖动、MIL 灯才洗 |
| 换刹车油提前 | 3 年/40,000 km 已足 | 每 40,000 km 或 3 年 | 检含水率（<3% 安），色深浅无变 |
| 换变速箱油提前（CVT） | 不必要 | 4S 基本换 60,000 km | 油色深、铁质质无烧看气味 |
| 换冷却液"全全" | 不必要 | 长效 coolant 16 万 km | 冷液色未变、无点查点 |
| 换火花塞提前 | 不必要 | 铱金 100,000 km | 拆火是否火不稳 |
| "深度养护"套装 | 多数无必要 | — | 查每项必要性，可拒单项 |
| 换电池（12V 电瓶）提前 | 不必要 | 3–5 年 | 转速低、压降 10V 以下才换 |
| 换"水防护液" | 多无效 | 每 2 年视地区 | 车内地区有霉才洗 |

## 混动/新能源专属

| 项目 | 周期/内容 |
|------|----------|
| 变频器冷却液（混动与 EV） | 首次 160,000 km 或 10 年，之后每 80,000 km |
| 动力电池冷却液 | 首次 40,000 km / 2 年，之后视检测报告 |
| 动力电池健康检测（SOH） | 每 24 个月进店检测 1 次（国内 4S）；20 万公里可享丰田免费检测 |
| 动力电池电压/内阻报告 | 每次 4S 入检测时调出 |
| 减速箱油（EV） | 首次 40,000 km，之后每 40,000 km 检查，视颜色/气味 |
| 高压线绝缘检测 | 每 40,000 km 或 3 年 |
| 三电质保细则 | 首任车主 8 年/20 万公里；非首任或超里程降为 8 年/16 万 km；要求丰田 4S 定期检记录（间隔 24 个月/1 次），在黑平台修理或事故失 |
| 混动 12V 电瓶 | 混动关闭发动机后负载，寿命较短，3 年检查 |

> **丰田混动车主提示：** 丰田 THS 在国内实行 20 万公里 / 10 年动力电池免费检测；4S 会主动召唤，但不影响 8 年质保基础条件。

## 旁路自保 Tips

1. **混动 20 万公里免费电池检测**：丰田首任车享 8 年 20 万 km 动力电池质保，4S 每 2 年召唤检测；备查回执存档，质保期内不要漏检。
2. **0W-20 机油识别**：丰田 0W-20 是日规 TG 原装，与 GF-6 后缀 API SP 同规；外油标 API SP / ILSAC GF-6 且粘度 0W-20 可用，保油贴标签自油含 0W-20。
3. **ATF WS 变速箱油不可混加**：丰田 CVT/AT 采用 ATF WS（JWS 336），与 ATF DEXRON 或其他品牌不兼容，混加导致伺服误动作。
4. **SLLC 冷却液颜色识别**：丰田超级长效冷却液为红色/粉红，与普通乙二醇绿液不可混加；更换记含冷却液标签为 "TOYOTA SLLC"。
5. **保养间隔按里程优先**：丰田国内手册以里程或时间先到为准；低里程车按时间（12 月）执行，不要拖延超期，否则影响质保凭证。
