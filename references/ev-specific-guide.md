# 新能源车专项指南

> 目的：覆盖新能源车（纯电 BEV / 插混 PHEV / 增程 EREV）独有的保养、质保、电池健康、充电、衰减索赔等全维度。
> 不重复 maintenance-intervals.md 的常规项，只讲新能源专属。
> 最后更新：2026-08

---

## 一、新能源车分类与差异

### 分类总表

| 类型 | 代表 | 动力源 | 维保核心 |
|------|------|--------|---------|
| **纯电 BEV** | 比亚迪海豚/Model 3/蔚来 ES6 | 三电 + 单速减速箱 | 三电 + 减速箱 + 热管理 |
| **插混 PHEV** | 比亚迪 DM-i/秦 DM-p | 发动机 + 电机 + 电池 | 兼油车 + 电机 + 电池 |
| **增程 EREV** | 理想 L 系列/问界 M7 增程 | 发动机仅发电 + 电机驱 | 电机 + 电池 + 增程器 |
| **混动 HEV** | 卡罗拉双擎/凯美瑞双擎 | 发动机为主 + 电机辅 | 兼油车 + 电机 + 电池 |

> **关键差异：** PHEV/EREV 有发动机，要做机油火花塞等油车保养；BEV 完全没有。HEV 发动机为主，保养接油车但加混动专属项。

### 各类型保养矩阵

| 保养项 | BEV | PHEV/EREV | HEV |
|--------|-----|-----------|-----|
| 机油+机滤 | ❌ | ✅ | ✅ |
| 火花塞 | ❌ | ✅（视发动机） | ✅ |
| 空气/空调滤芯 | ✅ | ✅ | ✅ |
| 减速箱油 | ✅ | ✅ | ✅ |
| 刹车油 | ✅ | ✅ | ✅ |
| 冷却液（发动机） | ❌ | ✅ | ✅ |
| 冷却液（电池） | ✅ | ✅ | ✅ |
| 冷却液（电机/逆变器） | ✅ | ✅ | ✅ |
| SOH 检测 | ✅ | ✅ | ✅ |
| BMS 固件升级 | ✅ | ✅ | ✅ |
| 充电口清洁 | ✅ | ✅ | ❌（HEV 不外充） |

## 二、三电系统详解

### 2.1 电池（Battery）

#### 锂电池类型

| 类型 | 常见品牌 | 特性 |
|------|---------|------|
| **磷酸铁锂 LFP** | 比亚迪刀片、特斯拉标续 | 寿命长（3000+ 循环）、耐过充、寒区放电差 |
| **三元锂 NCM** | 蔚来、Model 长续、广汽 | 能量密度高、寒区好、循环寿 <1500 |
| **锰酸锂 LMO** | 部分日系混 | 安全好、密度低、循环中 |

> **LFP vs NCM 选车逻辑：** 北方寒区优先 NCM（放电能力强）；南方 + 长期持有优先 LFP（循环寿更长）。

#### SOH（State of Health）解读

| SOH | 含义 | 建议动作 |
|------|------|---------|
| ≥95% | 近新车 | 无 |
| 90–95% | 正常衰减 | 无 |
| 85–90% | 可接受 | 关注趋势 |
| 80–85% | 接近警线 | 预约深度检测 |
| <80% | 可索衰减 | 联系售后索衰减（依质保条款） |

> **SOH 不是线性下降的。** 初期降快（前 2 年降 5–8% 是正常），中期稳（3–8 年降 1–2%/年），末期快（>10 年降 3–5%/年）。判定衰减是否"正常"要看年限×车型基准。

#### SOC（State of Charge）使用建议

| 使用场景 | SOC 范围 | 说明 |
|---------|---------|------|
| 日用通勤 | 30–80% | 最优区间，衰减最慢 |
| 长途出行 | 80–100% | 临行充满，到后即降至 80 |
| 长期停放 | 50–60% | 防满充饿损 |
| 寒区停放 | ≥60% | 低温下亏电损电更重 |
| 高温停放 | ≤70% | 满电 + 高温是衰减加速器 |

> **满充 + 满放是衰减双杀手。** 除非长途，否则 SOC 限到 80% 上限、20% 下限充电，可延寿 30–50%。

### 2.2 电机（Motor）

#### 永磁同步 vs 异步

| 类型 | 特性 | 常见 |
|------|------|------|
| **永磁同步 PMSM** | 效率高、体积小、高速退磁风险 | 多数纯电车 |
| **异步异步 ASM** | 成本低、高速好、低效 | 双电机车的异步辅助电机 |

#### 电机保养项

| 项 | 间隔 | 说明 |
|----|------|------|
| 减速箱油 | 4 万 km 检、6 万 km 换 | 不同于变速箱油，专用品 |
| 冷却液（电机回路） | 4 年或 8 万 km | 与电池回路独立 |
| 绝缘检测 | 每 24 月 | 4S/品牌售后专设备 |
| 轴承听诊 | 每 12 月 | 高频鸣响是早期征兆 |

> **电机几乎免维，但减速箱油不可忽略。** 高速工况下油温可达 100°C+，长期不换会致齿面磨损。

### 2.3 电控（Controller / BMS / Inverter）

#### BMS（电池管理系统）固件

- 建议每次进店升级到最新固件——BMS 算法迭代会优化衰减估算与充放电策略
- 部分品牌（蔚来/特斯拉/比亚迪）支持 OTA 远程升级，无需进店
- 升级后 SOC 跳变可能持续 1–2 周重算，属正常

#### 逆变器（Inverter）

- 几乎免维，靠冷却液散热
- 偶发"限功率"报警多半是温度保护策略，非故障
- 若频繁限功率即使冷车也限，需检测绝缘与 IGBT 模块

## 三、三电质保条款细则

### 各品牌质保条款对比

| 品牌 | 电池 | 限首任车主 | 跟车/跟人 | 进店要求 |
|------|------|-----------|---------|---------|
| **比亚迪** | 8 年/15 万 km | 否 | 跟车 | 无强制 |
| **特斯拉** | 8 年/16–19.2 万 km | 否 | 跟车 | 无强制 |
| **蔚来** | 首任终身质保 + 二任 8 年 | 是（首任终身） | 跟人（首任） | 每年至少 1 次 |
| **理想** | 首任终身 + 二任 8 年/12 万 km | 是 | 跟人（首任） | 每年至少 1 次 |
| **小鹏** | 首任终身 + 二任 8 年/15 万 km | 是 | 跟人（首任） | 每年至少 1 次 |
| **零跑** | 首任终身 + 二任 8 年/15 万 km | 是 | 跟人（首任） | 每年至少 1 次 |
| **广汽埃安** | 首任终身 + 二任 8 年/15 万 km | 是 | 跟人（首任） | 每年至少 1 次 |
| **哪吒** | 8 年/15 万 km | 否 | 跟车 | 无强制 |
| **深蓝** | 首任终身 + 二任 8 年/15 万 km | 是 | 跟人（首任） | 每年至少 1 次 |

### 质保失效条件（共性）

| 条件 | 是否失效 | 说明 |
|------|---------|------|
| 未按规进店检测 | ✅ 失效 | "终身"降级为"常规" |
| 单年里程 >3 万 km（部分品牌） | ✅ 失效 | 看 PL 条款 |
| 在第三方拆装三电 | ✅ 失效 | 含换油等"看似维保" |
| 重大事故致三电损 | ✅ 失效 | 走车损险 |
| 水浸、火烧 | ✅ 失效 | 走车损险 |
| 自然衰减（非故障） | ❌ 不赔 | 属正常磨损 |
| 雷击、电网故障 | ❌ 不赔 | 需"外部电网故障险"附加险 |

> **质保条款核心矛盾：** "终身"质保听起来诱人，但失效条件多。务必向销售索要书面条款，不要听口头承诺。

### 衰减索赔边界

| 阈值 | 是否可索 | 流程 |
|------|---------|------|
| SOH 降至 70% 以下 | 多数品牌可索换 | 售后检测 → 申请 → 厂家审核 → 更换 |
| SOH 降至 80% 以下 | 部分品牌可换 | 同上 |
| 单体压差 >150mV | 可索检测/换模组 | 售后检测 |
| 充电限功率（冷车也限） | 可索检测 | 售后检测 |
| 续航 <官方 70% | 部分品牌按衰减索 | 综合检测后定 |

> **"自然衰减" vs "故障衰减"的边界是质保争议焦点。** 厂家常以"自然衰减"拒赔，用户需凭第三方检测机构报告申诉。

## 四、充电系统

### 4.1 充电方式对比

| 方式 | 功率 | 时间（60kWh 电池） | 成本 | 适用 |
|------|------|-------------------|------|------|
| **交流慢充（家桩 7kW）** | 7 kW | 8–9 小时 | ¥0.5–0.6/kWh | 夜充日用 |
| **交流慢充（桩 11kW）** | 11 kW | 6 小时 | ¥1.0–1.5/kWh | 公司/商场 |
| **交流慢充（桩 22kW）** | 22 kW | 3 小时 | 同上 | 公共慢充 |
| **直流快充（50kW）** | 50 kW | 1 小时 | ¥1.5–2.0/kWh | 应急 |
| **直流快充（120kW）** | 120 kW | 30 分钟 | ¥1.8–2.2/kWh | 长途 |
| **直流超充（250kW+）** | 250 kW+ | 15 分钟 | ¥2.0–2.5/kWh | 特斯拉/蔚来自营 |

### 4.2 家用桩安装

#### 申请流程

```
1. 物业同意书 → 2. 电网报装（低压业扩）→ 3. 装表接电 → 4. 桩商安装 → 5. 桩检通电
```

| 步骤 | 时长 | 费用 | 注意 |
|------|------|------|------|
| 物业同意 | 1–7 天 | ¥0–500（部分物业收"管理费") | 必须书面同意 |
| 电网报装 | 7–30 天 | ¥0（国家政策免业扩费） | 需车位证 + 身份证 + 购车发票 |
| 装表接电 | 7–15 天 | ¥0 | 部分小区需管线改造 |
| 桩商安装 | 1–3 天 | ¥0–2000（含/不含安装看品牌） | 桩必装剩余电流保护 + 急停 |
| 桩检通电 | 1 天 | ¥0 | 部分地区需电网复检 |

> **家用桩成本最低，是 BEV 经济性核心。** 若无家桩，BEV 成本接近甚至超过油车。

#### 桩选购

| 品牌类型 | 价格 | 优势 | 风险 |
|---------|------|------|------|
| 原车厂桩（特斯拉/比亚迪/蔚来） | ¥3000–8000 | 配套稳定 | 锁桩 + 部分功能限 |
| 公牛/星星充电等三方 | ¥1500–3500 | 通用 + 便宜 | 售后分散 |
| 智慧家桩（带 RFID/计量） | ¥4000–12000 | 可计费 + 分享 | 部分需年检 |

### 4.3 公共充电桩使用技巧

#### 找桩策略

| 场景 | 推荐桩型 | APP/平台 |
|------|---------|---------|
| 商场/办公日常 | 慢充 7–22kW | 特来电/星星/国家电网 |
| 长途高速 | 快充 120kW+ | 高速服务区专用 |
| 应急补电 | 超充（特斯拉/蔚来自营） | 品牌自家 APP |
| 异地陌生 | 多平台聚合 | 充电联盟/度度充 |

#### 充电习惯

| 习惯 | 评价 |
|------|------|
| 满 SOC 80% 后断充 | ✅ 衰减最慢 |
| <30% 才充 | ✅ 避免浅充浅放 |
| 快充后立即静置 ≥10 分钟 | ✅ 电池冷却 |
| 雷雨夜充 | ❌ 桩端风险 |
| 雷天户外充 | ❌ 部分桩会自锁 |
| 高温快充完立即再快充 | ❌ 温度保护会限功率 |
| SOC 80–100% 用快充 | ❌ 后段充电慢且伤电 |

### 4.4 充电口保养

| 项 | 间隔 | 操作 |
|----|------|------|
| 直流口触点清洁 | 每 3 月 | 干布擦，禁液 |
| 交流口触点清洁 | 每 6 月 | 同上 |
| 口盖弹簧检查 | 每 12 月 | 手动开闭测试 |
| 口密封圈检查 | 每 12 月 | 看是否老化 |
| 口内异响检查 | 每 12 月 | 慢插慢拔不应响 |

> **充电口接触不良是偶发"无法充电"主因。** 触点氧化后电阻升高发热，长期会熔桩头与车口。定期清洁 + 闻有无焦味是简单有效的预防。

## 七、电池衰减索赔实战

### 索赔前提

1. 质保期内（终身质保按条款）
2. SOH 或衰减达索赔阈值
3. 非人为损坏（无第三方拆装、无水浸火烧、无事故）
4. 检测在品牌自营或合作机构完成

### 索赔流程

```
1. 售后申请 → 2. 品牌自营检测 → 3. SOH 报告 → 4. 厂家审核 →
5. 同意换/拒赔 → 6. (同意) 更换电池/模组 → 7. (拒赔) 第三方复检或诉
```

### 拒赔应对

| 拒赔理由 | 应对 |
|---------|------|
| "自然衰减" | 索检测报告，看是否压差大、单体异常 |
| "未按规进店" | 索书面进店记录，按合同比对 |
| "第三方拆装" | 若仅换刹车油等非三电项，不构成失效 |
| "事故损" | 走车损险，不走三电质保 |
| "里程超限" | 看是否首任终身 + 里程条款细则 |

### 第三方检测机构

| 机构 | 费用 | 用途 |
|------|------|------|
| 查博士 | ¥500–1500 | 电池深度报告 |
| 老司机检测 | ¥500–1200 | 同上 |
| 品牌合作检测 | 部分免费 | 厂家认可 |
