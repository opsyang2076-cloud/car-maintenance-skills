# 出险理赔实战手册

> 目的：补充 car-insurance-guide.md 的"买什么"维度，专门解决"出险后怎么办"——报案话术、现场处置、定损博弈、代位追偿、拒赔应对、小额私了临界值。
> 不替代专业律师或保险经纪人意见，但给车主一份可立即照做的实战手册。
> 最后更新：2026-08

## 一、事故第一分钟决策树

### 决策原则：分级处置，不要慌

```
事故
 ├─ 有人伤 → 必报交警 122 + 110 + 保险，不得私了
 ├─ 无伤但车不能开
 │   ├─ 在高速 → 必报警 + 救援 + 保险，移至硬路肩
 │   └ 不能移且堵路 → 拍完照按交规移至边，报交警
 │   └ 能缓行 → 拍完照就近平地，报保险
 ├─ 无伤且车能开
 │   ├─ �方全责 → 拍照 + 移车 + 报保险
 │   ├─ �方拒认全责 → 拍照 + 不移车 + 报交警
 │   └ 不确定责任 → 拍照 + 移车 + 报交警
 ├─ 单车事故（撞墙/树/栏）
 │   ├� �估损失 <500元 → 建议不走险，私了
 │   └ 损失 >500元 → 拍照 + 报保险
 └ 涉及豪车/公共设施/对方不认
     → �必报警 + 保险，私了风险极高
```

### 是否报警矩阵

| 场景 | 报交警 | 报保险 |
|------|--------|--------|
| 有人伤（含自己轻伤） | ✅ 必 | ✅ 必 |
| 双方车损 >2000 元 | ✅ 必 | ✅ 必 |
| 双方车损 <2000 元且责任明 | ❌ 否 | ✅ 必 |
| 单方轻微剐蹭 <500 元 | ❌ 否 | ❌ 否（私了） |
| 涉及豪车/公共设施 | ✅ 必 | ✅ 必 |
| 对方酒驾/无证/逃逸 | ✅ 必 | ✅ 必 |
| 雨天/夜间/隧道/高速 | ✅ 必 | ✅ 必 |
| 对方认全责 | ❌ 否 | ✅ 必 |

## 二、现场处置六步法

### Step 1 — 安全与撤离

- 撑三角警示牌：普通路 50m 后、高速 150m 后
- 全员撤离至边护栏外（高速必撤至护栏后）
- 开双闪，熄火，拉手刹
- 夜间/雨雾开示宽灯 + 雾灯

> **高速二次事故率比首事故死亡率高 10 倍。** 任何人伤 + 车损，先撤离再议事。

### Step 2 — 拍照取证七张

按以下顺序拍，**全部带对方车辆牌照**：

| # | 拍什么 | 要点 |
|---|--------|------|
| 1 | 全景（含两车位置+交通线） | 站 5–10m 外广角 |
| 2 | 全景（反方向） | 确认车道与责任 |
| 3 | 接触点特写（双方） | 含碰撞痕迹+车漆比对 |
| 4 | 对方牌照+车标+车型 | 必清晰 |
| 5 | 周边环境（红绿灯/标志/路口） | 证明责任 |
| 6 | 自己车损详图 | 含全车+特写 |
| 7 | 对方车损详图 | 含全车+特写 |

**拍照禁忌：**
- ❌ 不带时间戳（必开相机关闭"自动水印"——用 GPS 时间即可）
- ❌ 不拍对方驾照/行驶证原件（侵权）
- ❌ 不拍对方当事人正脸
- ❌ 移车后才拍

### Step 3 — 信息交换

**必问对方：**
1. 驾照姓名 + 联系电话
2. 行驶证车主名（公司与个人不同）
3. 牌照 + 车型 + 颜色
4. 保险公司名 + 保单号（如对方知道）
5. 是否酒驾/药驾/疲劳（注意语气，对方不必答但记录反应）

**禁忌：**
- ❌ 不要争吵责任——交交警定，自己说现场即可
- ❌ 不要承认全责即使你错——交交警与保险定
- ❌ 不要说"没事没事"——可能被录用作"无伤"证据
- ❌ 不要签任何对方给的纸（含"互不追究"）

### Step 4 — 报警/报保险

**报交警话术：**
```
"我是[姓名]，在[道路名+方向+公里数/路口]发生[追尾/侧撞/刮蹭/单车]
事故，[有/无]人员伤亡，[有/无]车辆堵塞，[能/否]自行移车，
对方车牌[XXX]，[已拍照/已撤离/未撤离]，请求[出警/电话处理]。
```

**报保险话术：**
```
"我是[姓名]，保单号[XXX]，车辆[车型+牌照]，于[时间地点]发生事故。
[对方车型+牌照]，[有/无]人伤，[有/无]豪车公共设施，
[已拍照7张+对方信息+已报交警]，请求[定损/拖车/代位]指引。
```

> **报保险必在 48 小时内完成。** 超 48 小时报案的部分保险公司可拒赔或减赔。最稳妥是事故现场即报。

### Step 5 — 移车

- 交警到场前，**若已拍照且堵路**，按交规移至边
- 高速**不能自行移车**除非交警电话指示
- 移车前最后拍一张"原位置到新位置"的轨迹照
- 移后开双闪占边

### Step 6 — 现场笔录与备忘

立即在手机备忘录记下：
- 事故时间（精确到分）
- 地点（含道路名+方向+参照物）
- 对方信息（姓名+电话+牌照+保单号）
- 交警/保险接线员工号
- 现场描述（动作+车速+红绿灯）
- 目击者联系方式（若有）

> 48 小时后凭这份备忘 + 照片做"事故报告"附给保险公司。

## 三、私了 vs 走保险临界值

### 临界值公式

```
走险划算 = 涨险差 > 修复费
私了划算 = 修复费 < 涨险差
```

### 涨险差参考

| 当前 NCD | 出险 1 次后 NCD | 涨险差（3 年累计） |
|---------|----------------|------------------|
| 0.50 | 1.00 | ¥3000–8000（视基准保费） |
| 0.60 | 1.00 | ¥2000–6000 |
| 0.70 | 1.00 | ¥1500–4500 |
| 0.85 | 1.00 | ¥500–2000 |
| 1.00 | 1.00 | ¥500–1500（出险后已无降升差，下次续保才体现） |

### 私了临界值速查

| 车主画像 | 私了临界值 |
|---------|----------|
| 长期未出险（NCD ≤0.70） | ¥1500–2000 以下私了 |
| 偶发出险（NCD 0.85） | ¥800–1200 以下私了 |
| 当年已出险 1 次（NCD 1.00） | ¥500–800 以下私了 |
| 当年已出险 2 次 | ¥1000 以下建议私了（拒保风险） |
| 当年已出险 3 次 | 全部私了（拒保或重加附加条件） |

> **临界值是"3 年累计涨险差"为基准的。** 不出险的 NCD 优惠要 4 年才能拉满 0.50，一次出险清零后又要等 4 年——这是为什么临界值比单年保费差更高。

### 不应私了的场景

| 场景 | 原因 |
|------|------|
| 涉及豪车 | 修复费可能数十万，私了风险极高 |
| 涉及公共设施 | 物损需官方定损，私了无法律效力 |
| 对方有明显酒驾/无证 | 私了对方后续可讹诈 |
| 对方逃逸倾向 | 私了无凭证 |
| 车损看似轻但可能伤结构 | 4S 拆检后可能 >10 倍报价 |
| 自己有特殊条款（网约车） | 私了可能违运营险条款 |

### 私了流程（必签）

```
1. 双方同意金额
2. 写"互不追究协议"含姓名+身份证+牌照+金额+签字+日期
3. 拍协议 + 转账（不要现金）
4. 立即撤保险报案（"已私了 XX 元"备案）
```

## 四、定损博弈

### 定损前置——4S 报价陷阱

| 陷阱 | 应对 |
|------|------|
| "按 4S 标准定损" | 同意 4S 报价后走保险按 4S 定损 |
| "初估 ¥2000，拆后 ¥20000" | 必要求保险公司参与拆检，自己不到场不签 |
| "换总成件" | 部分件可修复，不要默认同意换总成 |
| "原厂件 vs 副厂件" | 看险种，车损险多数按原厂，三者险按副厂 |
| "折旧率争议" | 车龄越旧折旧率越高，保险公司会按最低 |

### 定损流程

```
1. 保险公司定损员到 4S/修理厂看车 → 2. 出"定损单"含项+金额 →
3. 车主审单 → 4. 同意/争议 → 5. 修车 → 6. 取车 → 7. 保险公司付款/先垫后报
```

### 审定损单六查

| 查 | 看什么 |
|----|--------|
| 1 | 报修项目是否漏（事故痕迹对项目清单） |
| 2 | 单价是否市场价（4S vs 副厂标明） |
| 3 | 工时是否合理 |
| 4 | 折旧率是否合理（车龄 5 年内应在 ≤30%） |
| 5 | 残值扣法是否合理（旧件归保险公司不是车主） |
| 6 | 总额是否超保额（三者险 100 万就赔 100 万） |

### 定损争议应对

| 争议 | 应对 |
|------|------|
| 定损 <4S 报价 | 自己签 4S 报价给保险，要求按 4S 标准定损 |
| 不认某项修复 | 拆检视频/照片附争议函 |
| 残值扣法不一 | 同一公司同地区应一致，索历史案例 |
| 折旧率过高 | 同车型同车龄查定损平均值 |
| 定损员不专业 | 联系保险公司总部，索复定 |

## 五、赔款支付流程

### 5.1 自己车损（车损险）

```
1. 4S/修厂垫付 → 2. 保险公司付款给修车方 → 3. 车主取车（应无需再垫）
   或：保险公司直付 4S，车主 0 垫付（看险种含"无垫付服务"否）
```

### 5.2 对方车损（三者险）

```
1. 保险定损对方车 → 2. 直赔对方（不需自己经手）
   或：对方自付修车 → 拿发票 → 车主垫赔 → 保险公司还款
```

> **不要亲自接对方赔款再转保险——** 万一对方事后说"已赔过现金"，凭据争议极大。

### 5.3 代位追偿（对方全责不赔）

**代位追偿条件：**
1. 你方保险公司提供代位服务
2. 责任明确为对方全责（交警认定书）
3. 对方拒赔或久拖不赔

**流程：**
```
1. 廫你方保险公司申请代位 → 2. 提供责任认定书+对方信息 →
3. 保险公司先赔你 → 4. 保险公司向对方追偿 → 5. 对方拒赔可起诉
```

> **代位追偿是车主最强工具。** 自己保险公司先赔后向对方追，对你无影响（不视为出险）。但部分公司会以"代位不算出险"扣减 NCD，需问清。

## 六、拒赔应对

### 常见拒赔理由

| 理由 | 是否成立 | 应对 |
|------|---------|------|
| "未及时报案" | 部分成立 | 48 小时内报案成立拒赔无依据，超时需举证 |
| "驾照过期" | 成立 | 严格按保险条款，驾照过期属免责 |
| "酒驾/药驾" | 成立 | 同上 |
| "非约定的驾驶人" | 视条款 | 部分险种限驾驶人，看保单 |
| "无证或证不符" | 成立 | 严格拒赔 |
| "营运车按非营运投保" | 成立 | 滴滴/Uber 必须按营运投 |
| "未及时续检" | 部分成立 | 车龄 6 年内免上线，6 年后超期影响 |
| "故意行为" | 成立 | 故意撞不赔 |
| "战争/暴动/恐袭" | 成立 | 极少争议 |
| "充不足证据" | 部分成立 | 补照片+备忘+交警认定书 |

### 拒赔应对流程

```
1. �书面拒赔通知 → 2. 看具体免责条款 → 3. 与理赔员复核 →
4. 投诉至总公司 → 5. 投诉至银保监会（12378）→ 6. 诉讼
```

### 银保监会投诉话术

```
"我是[姓名]，保单号[XXX]，于[日期]向[公司名]报案后于[日期]被以
[理由]拒赔，我认为不符保单条款第[X]条，请求银保监会调解。
证据：保单+事故认定+拒赔通知+照片。
```

> **银保监会投诉比诉讼有效。** 12378 投诉后保险公司必在 15 日内书面回复，多数情况下会重新议赔。

## 七、小额事故实战速查

### 停车场剐蹭

| 情形 | 处置 |
|------|------|
| 对方在场且认 | 私了，互不追究协议 |
| 对方在场不认 | 报交警+保险 |
| 对方不在场 | 拍现场+对方牌照+监控调阅+报保险 |
| 监控无 | 走车损险（无现场也赔，但保费涨） |

### 被追尾

| 情形 | 处置 |
|------|------|
| 后方全责明 | 拍照+对方信息+报对方保险+代位备选 |
| 对方不认 | 报交警+不私了 |
| 高速被追尾 | 必报交警+人撤离+报保险 |
| 多车连追 | 各自责任由交警定 |

### 撞固定物（墙/树/桩）

| 情形 | 处置 |
|------|------|
| 单车 <500 元 | 私了（不走险） |
| 单车 >500 元 | 拍照+报保险+车损险赔 |
| 撞公共设施 | 报交警+保险，赔市政/园林/电信 |

### 撞动物

| 情形 | 处置 |
|------|------|
| 撞流浪动物 | 走车损险（涨保费） |
| 撞有主宠物 | 三者险赔（属物损） |
| 撞牲畜 | 报警+三者险 |

## 八、新能源车专属出险

### 电池事故定损

| 情形 | 定损 | 注意 |
|------|------|------|
| 电池外壳凹陷未变形 | 多数赔修复 | 拍"未触单体"证据 |
| 电池单体异常 | 赔单体或模组 | 看质保条款与车损险 |
| 电池包整体受损 | 赔电池包 | 高达 ¥5–15 万 |
| 电池涉水 | 赔全包 | 走车损险涉水条款 |
| 电池起火 | 赔全车 | 走车损险全损条款 |
| 充电桩端事故 | 看"外部电网故障险" | 无此险可能不赔 |

> **电池定损常争议。** 厂家常以"需返厂深度检测"推诿，要求保险公司支付检测费否则按全损赔。多数车损险含检测费。

### 充电桩损事故

| 情形 | 赔偿 | 来源 |
|------|------|------|
| 撞坏私桩 | 赔桩 | 走三者险或"新增设备损失险" |
| 撞坏公桩 | 赔桩 | 走三者险 |
| 充电中桩端故障致车损 | 赔车 | 走"外部电网故障险"附加险 |
| 充电中车端故障致桩损 | 赔桩 | 走三者险 |

## 九、与人伤相关

### 轻伤（擦挫扭）

| 项 | 处置 |
|----|------|
| 医药费 | 三者险赔（医保目录内） |
| 自费药 | 医保外用药责任险赔（必买附加） |
| 误工费 | 三者险赔，按工资证明 |
| 营养费 | 协议或诉讼 |
| 情感伤害 | 协议 |

### 重伤/死亡

| 项 | 上限（2026 一线标准） |
|----|---------------------|
| 死亡赔偿金 | ¥150–220 万 |
| 伤残赔偿金 | 按等级比例 |
| 被扶养人生活费 | 视扶养人数 |
| 精神损害抚慰 | ¥5–20 万 |

> **三者险额度建议一线 300 万起，500 万为佳。** 一线死亡赔偿单人就超 150 万，若多人伤或伤豪车，200 万保额会不够。

### 人伤流程

```
1. 立即叫120+报交警+报保险 → 2. 垫付必要医药费（保留凭证）→
3. 交警责任认定 → 4. 伤情鉴定 → 5. 调解或诉讼 → 6. 保险赔付
```
