# 养车成本计算器

> 目的：给车主一份**结构化的养车月度/年度成本估算工具**，覆盖能源、保养、保险、折旧、停车、路桥、清洗、罚款等全口径。
> 工作方式：对话式收集参数 → 按本文档公式逐项算 → 输出月度/年度汇总 + 节流建议。
> 最后更新：2026-08

---

## 一、成本分项总览

养车总成本 = **固定成本 + 变动成本 + 隐性成本**

| 大类 | 分项 | 是否固定 | 文档锚点 |
|------|------|---------|---------|
| 固定 | 保险费 | 年付 | §2.1 |
| 固定 | 车船税 | 年付 | §2.2 |
| 固定 | 年检费 | 年付（6年内免检，之后每年） | §2.3 |
| 固定 | 停车位（租或买） | 月付 | §2.4 |
| 变动 | 能源费（油/电/氢） | 按里程 | §3.1 |
| 变动 | 保养费 | 按里程/时间 | §3.2 |
| 变动 | 路桥费（高速/市区费） | 按出行 | §3.3 |
| 变动 | 洗车费 | 按频次 | §3.4 |
| 变动 | 罚款与扣分 | 概率性 | §3.5 |
| 隐性 | 折旧 | 按年限/里程 | §4.1 |
| 隐性 | 资金占用成本 | 按车价 | §4.2 |
| 隐性 | 时间成本（找车位/保养/排队） | 按用车强度 | §4.3 |

> **隐性成本最容易被低估。** 一辆 20 万的车年均折旧 2–3 万，比油钱贵得多。输出时必须把隐性成本单列，否则用户会误判"养车不贵"。

## 二、固定成本

### 2.1 保险费

引用 [car-insurance-guide.md](car-insurance-guide.md) 的方案 A/B/C，按用户车龄/价值/地区选型后取年保费。

| 方案 | 适用 | 年保费参考 |
|------|------|-----------|
| A 新车/高价值 | 车龄 ≤3 年或车价 >20 万 | ¥5,000–12,000 |
| B 家用性价比 | 车龄 4–7 年，车价 8–20 万 | ¥3,000–7,000 |
| C 老旧车 | 车龄 ≥8 年 | ¥1,500–3,000 |

**计算公式：**
```
年保险费 = 基准保费 × NCD系数 × 地区系数
```

| 连续无出险年数 | NCD系数 |
|--------------|---------|
| 0 年 | 1.00 |
| 1 年 | 0.85 |
| 2 年 | 0.70 |
| 3 年 | 0.60 |
| 4 年 | 0.50 |

| 地区 | 地区系数 |
|------|---------|
| 一线城市（京沪穗深） | 1.15 |
| 省会/计划单列 | 1.05 |
| 其他地级市 | 1.00 |
| 县城/乡镇 | 0.95 |

### 2.2 车船税

按排量分档，新能源车免征（2027 年底前政策）。

| 排量 | 年税额 |
|------|--------|
| ≤1.0L | ¥60–360 |
| 1.0–1.6L | ¥300–540 |
| 1.6–2.0L | ¥360–660 |
| 2.0–2.5L | ¥660–1200 |
| 2.5–3.0L | ¥1200–2400 |
| 3.0–4.0L | ¥2400–3600 |
| >4.0L | ¥3600–5400 |

> 具体税额各省在国标区间内自定，输入"所在省 + 排量"时查最新标准。

### 2.3 年检费

| 车龄 | 检测频次 | 单次费用 | 说明 |
|------|---------|---------|------|
| 0–6 年 | 免上线检测，仅每 2 年领标 | 免费 | 6 年内新车 |
| 6–10 年 | 每 2 年上线 | ¥300–500 | 含安检+环检 |
| 10–15 年 | 每年上线 | ¥300–500 | |
| >15 年 | 每半年上线 | ¥300–500 | |

> 新能源车 6 年内免环检，但仍需安检。

### 2.4 停车位

| 方式 | 月成本范围 | 说明 |
|------|-----------|------|
| 自有车位 | ¥0（但占资金，见 §4.2） | 车位本身 10–80 万 |
| 固定租车位 | ¥150–800 | 一线小区 ¥500–1500 |
| 路侧停车 | ¥100–400 | 含部分夜间免费段 |
| 单位免费 | ¥0 | 但通常排队抢位 |
| 随机找位 | ¥0–300 | 时间成本高，见 §4.3 |

**月停车费公式：**
```
月停车 = 主停车位租金 + 公司/常去场所停车 + 违章停车罚款均摊
```

## 三、变动成本

### 3.1 能源费

#### 燃油车

```
月油费 = 月里程 × 油耗(L/100km) / 100 × 油价(元/L)
```

| 油耗分档 | 类型 | 参考 |
|---------|------|------|
| 4–6 L/100km | 混动轿车 | 卡罗拉双擎、凯美瑞双擎 |
| 6–8 L/100km | 紧凑型轿车 | 卡罗拉、朗逸、思域 |
| 8–10 L/100km | 中型轿车/SUV | 凯美瑞、CRV、途观 |
| 10–13 L/100km | 中大型SUV/MPV | 汉兰达、奥德赛、GL8 |
| 13–18 L/100km | 豪华/性能 | BBA 2.0T+、跑车 |
| >18 L/100km | 大排量/越野 | 陆巡、牧马人 |

**油价参考（2026 全国均价）：**
- 92#：¥7.6–8.2/L
- 95#：¥8.1–8.7/L
- 98#：¥9.0–9.6/L
- 0#柴油：¥7.4–8.0/L

> 油价随国际原油波动，输出时标注"以当日本地油价为准"。

#### 纯电车

```
月电费 = 月里程 × 百公里电耗 / 100 × 电价
```

| 电耗分档 | 类型 | 参考 |
|---------|------|------|
| 11–14 kWh/100km | 紧凑型 | 比亚迪海豚、秦EV |
| 14–17 kWh/100km | 中型轿车/SUV | Model 3、汉EV、小鹏P7 |
| 17–22 kWh/100km | 中大型SUV | Model Y、蔚来ES6、理想L9 |
| 22–28 kWh/100km | 大型SUV/MPV | 理想L9、蔚来ES8 |

**电价分场景：**

| 充电方式 | 电价 | 说明 |
|---------|------|------|
| 家用桩（居民电） | ¥0.50–0.60/kWh | 含阶梯电价第三档风险 |
| 公共慢充 | ¥1.2–1.8/kWh | 含服务费 |
| 公共快充 | ¥1.5–2.2/kWh | 含服务费，高速服务区更贵 |
| 超充（特斯拉/蔚来） | ¥1.8–2.5/kWh | 部分含会员权益 |

**混合估算：** 多数车主家充占 70% + 公充 30%，加权电价约 ¥0.8–1.1/kWh。

#### 插电混动/增程

```
月能源费 = 纯电里程 × 电耗 × 电价 + 燃油里程 × 油耗 × 油价
```

> 关键参数：**纯电里程占比**。家有桩且通勤 ≤50km 的用户纯电占比可达 80%+，接近纯电成本；无家充则接近油车成本。

### 3.2 保养费

引用 [maintenance-intervals.md](maintenance-intervals.md) + [fault-diagnosis.md](fault-diagnosis.md)，按保养等级累计。

| 保养级别 | 单次参考 | 年频次（1.5万km/年） |
|---------|---------|--------------------|
| 小保 A | ¥300–600 | 1–2 次 |
| 大保 B | ¥600–1200 | 1 次 |
| 中保 | ¥1200–2500 | 0.5 次（2 年 1 次） |
| 大保 C | ¥2500–5000 | 0.25 次（4 年 1 次） |
| 深度养护 | ¥5000–10000 | 0.15 次（6–8 年 1 次） |

**年保养费估算公式：**
```
年保养 = Σ(各级别单次价 × 年频次) × 渠道系数
```

| 渠道 | 系数 |
|------|------|
| 4S 店 | 1.00 |
| 连锁（途虎/京东/天猫） | 0.65 |
| 独立修理厂 | 0.45 |

**例：** 1.5 万 km/年家用车，4S 店：
```
小保 450 × 1.5 + 大保 900 × 1 + 中保 1800 × 0.5 = 675 + 900 + 900 = ¥2475/年
```

### 3.3 路桥费

| 类型 | 月成本估算 |
|------|-----------|
| 市区通勤（无收费） | ¥0 |
| 偶尔高速（每月 1–2 次跨城） | ¥100–300 |
| 频繁跨城/出差 | ¥500–1500 |
| ETC 95 折优惠 | 通行费 × 0.95 |

### 3.4 洗车费

| 频次 | 月成本 |
|------|--------|
| 每周 1 次（自助/会员） | ¥60–120 |
| 每两周 1 次（普通） | ¥40–80 |
| 每月 1 次（精洗） | ¥50–100 |
| 季节性（北方冬季除雪盐） | ¥30–60 |

### 3.5 罚款与扣分

按城市驾驶风格和车主记录估：

| 车主画像 | 月均罚款 |
|---------|---------|
| 老司机+小城市 | ¥0–50 |
| 普通车主+二线 | ¥50–150 |
| 一线高频通勤 | ¥150–400 |
| 新手+异地上牌 | ¥200–500 |

> 这项是**概率性**的，建议按近 12 个月实际罚款取均值，新车主按中位数 ¥100/月估。

## 四、隐性成本

### 4.1 折旧

折旧是养车**最大单项成本**，但常被忽视。

#### 直线折旧法（粗估）

```
年折旧 = 购入价 × 年折旧率
```

| 车龄 | 年折旧率（燃油） | 年折旧率（新能源） |
|------|----------------|------------------|
| 第 1 年 | 15–20% | 25–35% |
| 第 2 年 | 10–15% | 20–25% |
| 第 3 年 | 8–12% | 15–20% |
| 第 4–5 年 | 6–10% | 12–18% |
| 第 6–8 年 | 5–8% | 8–15% |
| 第 9–10 年 | 4–6% | 5–10% |
| >10 年 | 3–5% | 3–8% |

> 新能源车因技术迭代快+电池衰减焦虑，前 3 年折旧显著高于同价燃油车。

#### 里程修正

```
实际折旧 = 直线折旧 × 里程系数
里程系数 = max(1.0, 实际里程 / 标准里程)
标准里程 = 1.5 万 km/年
```

> 跑得越多折旧越快，超 2 万 km/年时里程系数放大折旧。

### 4.2 资金占用成本

```
年资金成本 = 购入价 × 贷款利率（若贷款） 或 购入价 × 机会收益率（若全款）
```

| 情况 | 费率 |
|------|------|
| 贷款 3 年 5% | 购入价 × 5% × 平均未还余额比 |
| 全款（对标理财 3%） | 购入价 × 3% |
| 全款（对标房贷 4%） | 购入价 × 4% |

**例：** 20 万全款车，对标 3% 理财，年资金成本 ¥6000。

### 4.3 时间成本

```
年时间成本 = (找车位时长 + 保养排队时长 + 年检时长 + 充电等待时长) × 时薪
```

| 项目 | 年时长参考 |
|------|-----------|
| 找车位 | 30–60 分钟/天 × 250 天 = 125–300 小时 |
| 保养排队 | 2–4 小时/次 × 2–3 次 = 4–12 小时 |
| 年检 | 0.5–2 小时/年 |
| 充电等待（纯电） | 30–60 分钟/周 × 50 周 = 25–50 小时 |

> 多数车主**低估此项**。一线通勤族年找车位 200+ 小时，按时薪 ¥50 算就是 ¥10000 隐性成本。

## 六、节流策略速查

| 项 | 节流手段 | 年省 |
|---|---------|------|
| 保险 | 连续无出险拉满 NCD，三家比价，老车弃车损 | ¥500–3000 |
| 能源 | 拼电车加家充桩；油车改 92#（若厂家允许）；错峰充电 | ¥1000–5000 |
| 保养 | 连锁代替 4S；机油自购正品；按手册不超前保养 | ¥500–2000 |
| 停车 | 与单位/邻居拼租车位；夜间路侧免费段 | ¥1000–5000 |
| 路桥 | ETC 95 折；避开收费段绕行 | ¥100–800 |
| 洗车 | 会员套餐；自助洗车位 | ¥200–600 |
| 罚款 | 装行车记录仪+电子提醒；停在正规位 | ¥200–2000 |
| 折旧 | 降档换车；延长持有；二手车买进 | ¥3000–10000 |
